# 🧮 Calculator

A simple and user-friendly **Calculator** built using **HTML, CSS, and JavaScript**.
 This project performs basic arithmetic operations with a clean and responsive interface.

## 🚀 Features

* Addition
* Subtraction
* Multiplication
* Division
* Clear/Reset button
* User-friendly interface
* Responsive design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 💻 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start using the calculator.

## 🎯 Purpose

This project was created to practice **HTML structure, CSS styling, and JavaScript functionality**.
